# Финансы

Личный финансовый калькулятор Дмитрия. Первая функция моделирует замещение внешнего кредита собственным капиталом компании по методике «банка собственника».

## Команды

```bash
npm install
npm run dev
npm test
npm run build
```

## Модель

- банковский платёж считается по аннуитетной формуле;
- ежемесячные взносы накапливаются в течение года;
- при ежегодном рефинансировании накопленная сумма заменяет равную часть внешнего займа;
- заданная доля экономии банковского платежа добавляется к следующему ежемесячному взносу;
- избыток после полного замещения внешнего займа считается резервом.

Расчёт информационный: фактические комиссии, страховки, график и условия досрочного погашения определяются кредитным договором.
